# Художественное направление: Хоппак

Владелец: Hopper Design. Черновик по коду v0.53/v0.54 и мокапам концептов. Дизайнер может переписать и уточнить.

Обновлено: 25 ноября 2026, Europe/Moscow.

## Принцип

Пиксель — язык игры, не экономия. Один шрифт, одна палитра, спрайты и UI живут в одной сетке. Новые градиенты, блики и нейро-правкa поверх пикселей не допускаются. К 9 декабря новый арт не планируется: мокапы рисуются функциями самой игры.

## Поле и масштаб

Логика забега 160×346. На телефоне канвас занимает весь экран, остаток по бокам — небо карты (`viewPad`), не чёрные поля. На широком десктопе — letterbox цветом неба, рамка cream/navy, подсказка клавиатуры. `imageRendering: pixelated`. На телефоне масштаб может быть дробным (nearest-neighbor чуть «размазывает» глифы) — это известный эффект, не смена стиля.

## Палитра (код, объект `C`)

| Имя | Hex | Роль |
|-----|-----|------|
| ink / navy | `#0c0818` / `#162040` | текст, рамки, глубина |
| cream | `#f6ecd0` | светлая рамка, бумага UI |
| coral | `#ff645e` (также red `#ff5a62`) | только опасность |
| mint / edge | `#62e6be` / `#5ee0d0` | только главное действие |
| gold / goldD | `#ffd046` / `#b07a10` | монеты, награды, акцент |
| silver / bronze | `#b8c0d0` / `#c48448` | ранги лиг (концепт) |
| wood / brick | дерево платформ, городская кладка | мир |

Правило аудита, принятое в мокапах: mint — главное действие, coral — опасность (рамка «Нашествия», смерть). Покупка не должна быть «золото на коралле в один тап».

## Шрифт и UI

Встроенный пиксельный шрифт 5×7 (`FONT`). Только глифы, которые в нём есть: кириллица и набор знаков, без тире «—» и латиницы в текстах интерфейса, если глифа нет. Кнопки не ниже 18 px логики. Сетка меню 2×2; новые входы (справочник, задания) не ломают её без нужды. Способность в мокапах — нижняя полоса 152×26, не круглая кнопка в зоне «вправо» (A/B ещё открыт).

Мокапы концептов: 390×844, то же поле, тот же шрифт, живые `drawJumper` / `drawCoin` / `drawItem` / `drawMob` / `spawnParts`. Имена в мокапах (Рома, Лера, Макс, Катя, Дима, код 4821) — примеры, не канон вселенной.

## Персонажи и мир

Позы спрайта: idle, squash, up, fall, ability, ko, blink. Масштаб спрайта `SPR_SC = 3`. У каждого героя свой капюшон/силуэт, способность читается позой, не подписью в забеге.

Иконки бонусов в коде всё ещё квадраты 10×10. Обновлённый арт бонусов отложен; справочник и магазин должны вызывать живые функции отрисовки, чтобы будущий редизайн подхватился сам.

`save.color` и `save.hat` в сохранении есть, `makeLook` их игнорирует — косметики в сборке нет.

## Чего не делаем

Новогоднюю тему к 9 декабря не вводим. Не добавляем второй визуальный стиль «для сторов». В онлайне косметика (следы, рамки, перекрасы, эмоции) должна быть видна друзьям и не менять хитбоксы.
