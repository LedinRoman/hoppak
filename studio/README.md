# studio/ — единый источник правды

Документы студии по игре «Хоппак». Код игры и сервера сюда не входит и отсюда не правится.

Пишем коротко, по-русски, без воды. Неподтверждённое помечаем «неизвестно». Факты, гипотезы и оценки не смешиваем. Статусы решений: **предложено / утверждено / реализовано / проверено**.

Обновлено: 25 ноября 2026, Europe/Moscow.
