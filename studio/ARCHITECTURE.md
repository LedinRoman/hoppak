## Клиент

Исходники: `game/src/01_core.tsx`, `02_world.tsx`, `03_draw.tsx`, `04_shell.tsx`, `net.tsx`. Сборка: `game/build.sh` склеивает src в `hoppak.page.tsx`, собирает `hoppak.js` и минифицированный TSX в `game/page-build/` для Canvas. Локальный запуск: `game/index.html`.

Клиент — один ручной canvas-бандл без npm-импортов (также уходит как Canvas Page). Онлайн в page-сборке прячется флагом `HOP_PAGE`. Адрес сервера: тот же хост `/ws`, либо `?server=wss://…/ws`, `window.HOPPAK_SERVER`, `localStorage['hoppak.server']`.

Модель онлайна — «authoritative-light»: сервер не переигрывает физику, а задаёт seed, стартовое время, комнату и рассылает снапшоты. Клиент симулирует только своего героя (~15 Гц вверх), удалённых рисует с интерполяцией (~150 мс назад). События: `dead`, `mob`, `left`. Античит (повтор симуляции на сервере) — в планах `server/README.md`, не сделан. Подозрительно быстрый набор высоты только считается (`suspicious`), не отвергается.

## Сервер (код сейчас)

NestJS 11 + `@nestjs/platform-ws`, простой WebSocket, не socket.io (на клиенте нативный `WebSocket` = 0 КБ). Один процесс на порту 8787 отдаёт статику (`/`, `/hoppak.js`) и `/ws`, плюс `/api/health`. Комнаты в памяти: один инстанс; для нескольких инстансов в README указаны Redis и sticky sessions, в репозитории Redis/Postgres ещё нет.

Лобби: хост создаёт комнату, друзья входят по коду из 4 цифр, ready, хост стартует. Пустые комнаты удаляются сразу, простаивающие — через 1 ч. Защита: clamp чисел, высота не убывает, flood 60/с мягко и 180/с кик, правила входа/старта на сервере. AFK: тишина 15 с завершает участие.

Демо без своего хостинга: `server/scripts/demo.sh` (Cloudflare quick tunnel или ngrok). URL меняется при каждом перезапуске, пишется в `server/demo-url.txt`.

## Инфраструктура

Владелец раздела: Hopper Devops.

**Решение (утверждено 25.11.2026):** игра живёт на Hostinger KVM 2 Романа (2 vCPU, 8 ГБ RAM, 96 ГБ, оплачен до 25.02.2027). По оценке Devops этого хватит примерно на 500 игроков онлайн. Сервер 25.11 очищен (старый OpenClaw снесён). Oracle Always Free отклонён. Домена нет. Релиз друзьям 9.12 всё равно требует HTTPS.

**Порядок платформ (Devops):** сначала браузер, затем Mini App в Telegram, мобильные сторы позже.

**Целевой стек (план Devops, в текущем `docker-compose.yml` этого ещё нет):** свой бэк на NestJS, Postgres и Redis в Docker, Caddy для HTTPS, фронт на Cloudflare Pages (бесплатно), деплой через GitHub Actions. Следующий шаг Devops на 25.11 — базовая настройка сервера (Docker, файрвол, HTTPS). Без домена — HTTPS по адресу на основе IP.

**Что в репозитории сейчас:** `server/docker-compose.yml` собирает один сервис `hoppak`, порт `127.0.0.1:8787`. `server/DEPLOY.md` описывает nginx + certbot и домен `hoppak.example.com` и помечает, что выкладки ещё не было. Это документ ветки net, он не догоняет решение по Hostinger/Caddy/отказу от домена.

Нужные от Романа вещи по старому DEPLOY.md (SSH, домен, Docker/Node 22) частично перекрыты: сервер есть, домена нет, доступ — зона Devops.
