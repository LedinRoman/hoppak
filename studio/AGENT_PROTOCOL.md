# Протокол работы агентов Хоппака

Коротко: меньше пробуждений, один полный бриф, проверенные факты.

## Шаблон задачи

```
Цель: что должно получиться (1–2 строки).
Контекст: ветка, коммит, файлы, ссылки, что уже решено.
Сделать: пункты. Не трогать: границы.
Готово, когда: проверяемые критерии.
Сдать: куда пушить / какой артефакт / кому отчёт.
Лимит: effort и время.
```

## Шаблон отчёта

```
Итог: сделано / не сделано (1–2 строки).
Проверено: что запускали и что увидели (коммит, команда, адрес).
Не проверено: честно.
Изменилось: файлы, миграции, деплой.
Нужно от Романа: решение или ничего.
```

## Эскалация к Роману

Деньги, концепция, даты, инфраструктура (прод, база, домены, секреты) — только с его решением. Остальное решает исполнитель.

## Правила

- Tester запускаем только после OK Романа на полный RC на стейдже.
- Code сам смоук-тестирует свои исправления до сдачи.
- Картинки делает ChatGPT через Advisor; кодом и руками арт не рисуем, если Роман не сказал иначе.
- Экономия usage:
  - будим только тех ботов, кто нужен;
  - сообщения-FYI с priority false;
  - без пинг-понга между ботами;
  - один полный бриф сразу исполнителю;
  - тяжёлый код отдаём облачным агентам на low/medium effort.
- Changelog пишем только относительно прошлого прода, а не между rc.
- Секреты (токены, пароли, ключи, строки подключения) не попадают в чаты, логи и коммиты.
- Прод: сначала дамп, откат только из дампа (см. `deploy_bluegreen/PROD-0.6.1-PLAN.md`).
