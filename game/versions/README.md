# Каталог версий на стейдже

После согласования выкладки скопируйте файлы на стейдж в следующие места.

- `versions.html` → `/srv/hopper-staging/site/versions/index.html`
- `deploy/versions.staging.json` → `/srv/hopper-staging/site/v/versions.json`

Если релиз пересоздаёт каталог `site`, выполните копирование после выкладки игры. Проверьте `/versions` и `/v/versions.json` на стейдже. Стейдж для релиза 0.9 открывается по `/stage/`. Из архива доступны `/v/0.6rc/` и продовая стабильная сборка `/v/0.6/`.

Сначала выложите на стейдж клиент с поддержкой `409 DEVICE_REPLACED` из `feat/v1-backend-client`. Убедитесь, что открытые Telegram-сессии обновились, прежде чем выкатывать сервер профилей с новым ответом. Старые сборки обрабатывают только `401 SESSION_REPLACED`.

Для телеметрии и контраста примените миграции на стейдже и задайте `ADMIN_TOKEN` в окружении игрового сервера. Откройте `/api/admin` на стейдже и введите токен в поле страницы.
