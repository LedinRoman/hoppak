# v0.56 vs v0.57/v0.58 ширина на iPhone 390×844@3

Мир не менялся: LW=160, LH=346, платформы на seed 7 до 200 м одинаковы
(n=85, w 39–54, среднее 46.46, разброс x 4..156, отступ от стен 4).
Узже стало только из‑за целочисленного масштаба k в 0.57.

## Варианты (только ветка exp/v058-wide, в client/v058 не вливать)

1. **fill (предложено)** — вернуть дробный nearest-neighbor из 0.56. Видимая высота мира остаётся 346. LW не меняется. Константа `PHONE_SCALE.mode = "fill"`. Физика и раскладка платформ те же, прогон 450 ботов не нужен. Пиксели не стоят на целой device-сетке (k=7.3125), как в 0.56.

2. **integer** — текущий v0.57/v0.58, `PHONE_SCALE.mode = "integer"`. k=floor, поля по бокам.

3. **k=8 — не подходит.** 390×844@3 даёт 1170×2532 device px, для k=8 нужно 1280×2768. Если всё же поставить 8, видимая высота станет 2532/8 = 316.5 < 346, ширина 1170/8 = 146.25 < 160. Это ломает правило «одинаковая видимая высота поля на всех устройствах».
